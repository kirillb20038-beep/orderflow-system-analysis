OrderFlow — система управления заказами интернет-магазина

О проекте

OrderFlow — учебный проект по системному анализу, посвящённый проектированию системы управления заказами интернет-магазина.

Цель проекта — проработать требования, бизнес-процессы, модель данных и REST API, а также описать обработку ошибок и альтернативные сценарии оформления заказа.

Функциональность

Просмотр каталога товаров и доступных остатков.

Создание и просмотр заказов.

Отмена заказа с учётом его статуса.

Проверка доступности товаров при оформлении заказа.

Обработка повторных запросов с использованием механизма идемпотентности.

Структура проекта

Статус проекта

Учебный проект для портфолио системного аналитика. Документация описывает проектируемое поведение системы; полноценное работающее приложение в рамках данного проекта не реализовано.

Критическое требование: создание заказа, запись позиций и уменьшение доступного остатка должны быть одной транзакцией. Для защиты от конкурентных запросов остатки блокируются на время проверки/обновления либо обновляются условным атомарным запросом.
