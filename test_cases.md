# Тест-кейсы OrderFlow

| ID | Сценарий | Предусловия / данные | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Получение каталога | Есть активные товары | `200`; возвращаются поля товара |
| TC-02 | Создание заказа | Остатка достаточно; корректный ключ | `201`; статус `NEW`; остаток уменьшен |
| TC-03 | Нулевое количество | `quantity=0` | `400 VALIDATION_ERROR`; данных нет |
| TC-04 | Отрицательное количество | `quantity=-1` | `400`; данных нет |
| TC-05 | Пустой список | `items=[]` | `400`; заказ не создан |
| TC-06 | Несуществующий товар | `product_id` отсутствует в БД | `404 PRODUCT_NOT_FOUND`; остатки не меняются |
| TC-07 | Недостаточный остаток | Запрошено больше, чем доступно | `409 INSUFFICIENT_STOCK`; заказ не создан, все остатки прежние |
| TC-08 | Повтор успешного запроса | Тот же ключ и то же тело | Возвращается первоначальный результат; второй заказ не создан |
| TC-09 | Ключ с другим телом | Ключ уже использован, тело отличается | `409 IDEMPOTENCY_KEY_REUSED` |
| TC-10 | Просмотр заказа | Существующий ID | `200`; заказ и позиции соответствуют БД |
| TC-11 | Несуществующий заказ | Неизвестный ID | `404 ORDER_NOT_FOUND` |
| TC-12 | Отмена нового заказа | Статус `NEW` | `200`; статус `CANCELLED`; остатки восстановлены |
| TC-13 | Повторная отмена | Статус `CANCELLED` | `409 ORDER_NOT_CANCELLABLE`; остатки не изменились |
| TC-14 | Параллельная покупка последней единицы | Остаток 1, два одновременных заказа по 1 | Только один заказ успешен; остаток 0, не отрицательный |
| TC-15 | Откат при ошибке | Искусственная ошибка до commit | Заказ, позиции и остаток не изменены |
| TC-16 | Цена изменилась после покупки | Заказ создан, затем изменена цена товара | В заказе отображается зафиксированная `unit_price` |

## Приоритет
- **P0:** TC-02, TC-07, TC-08, TC-12, TC-13, TC-14.
- **P1:** TC-01, TC-03–TC-06, TC-09–TC-11, TC-15, TC-16.

## Примечание
TC-14 и TC-15 требуют интеграционного теста с реальной БД или управляемыми конкурентными транзакциями; их нельзя полноценно подтвердить только проверкой UI.
